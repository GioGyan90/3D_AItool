# Shape3D Studio

[在线打开 Shape3D Studio](https://giogyan90.github.io/3D_AItool/studio/)

Shape3D Studio 是一个浏览器 3D 编辑器，支持参考图描线、顶点编辑、材质调整和场景项目保存。通过 **项目 → 打开项目文件** 载入自己的 `.shape3d.json` 工程。选中带控制网格的图层后，点击 **编辑顶点**。

## 本地运行

需要 Node.js。在仓库根目录运行：

```sh
npm ci
npm run dev
```

本地使用 AI 功能时，在 `.env.local` 中配置 `GEMINI_API_KEY`。

## 构建在线版

运行 `npm run build:pages`，产物生成在 `docs/studio/`。公开构建关闭需要 API 密钥的 AI 功能。

## 基础形状布线建模（局部造型工具版）

主编辑器顶部新增 **布线建模**：

1. 选中立方体、球体或圆柱体后点击「布线建模」；无选中图层时会创建一个可编辑立方体。已有控制网格可以直接进入。
2. 基础形状会转换为 `csg` 控制网格（低多边形：立方体 6 个四边面；球体 12 经线、6 纬线；圆柱体 12 边），保留原图层的位置、旋转、缩放和材质。
3. 选择「正交编辑」→「选择/移动」，点击橙色边线。在右侧「布线建模 · Edge Loop」栏选择起始边和布线位置，点击「沿四边面插入环线」。
4. 新增环线由真实共享顶点和四边面组成；3D 预览中也可以直接选择橙色边、灰色面和蓝色顶点。四个机位可快速检查轮廓。
5. 通过「局部切割」只分割选中四边面并自动拆分邻面，避免共享边出现 T 形断点；「面内插」围绕选中面增加一圈四边面；「面挤出」沿该面法线生成盖面和侧壁。镜像要求先建好 X 坐标单侧的半模型，X=0 中线自动焊接并删除中心封盖。顶部「撤销/重做」支持 50 步及 Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y），可配合顶点拖动使用。
6. 预览确认后点击「应用到场景」。使用「项目 → 保存项目」保存为 `.shape3d.json`；已应用的网格可再次进入布线工具。

**当前边界：** 完整环切只能跨四边面；局部切割仅限选中四边面，邻接面可能被拆成三角形和多边形；面挤出为沿法线的独立单面挤出，不支持交互式连续拖距或桥接；镜像仅支持 X=0 且要求已有中线。非流形边、错误相邻面绕序、不安全切线会被拒绝。带倒角、自定义锚点或形变的基础形状暂不允许直接转换，以免破坏既有造型。转换后的控制网格可使用已有的顶点编辑功能。

测试：`npm run test:topology`；类型检查：`npm run lint`；在线版生成：`npm run build:pages`。已配置 GitHub Actions：类型检查和拓扑测试通过后自动构建并写回 `docs/studio/`。静态资源已更新后仍需 GitHub Pages 部署生效；如看到旧版请查看 Actions / Pages 状态并强制刷新。

## 浏览器验收与截图

CI 包含 `npm run lint`、`npm run test:topology`、`npm run build:pages`，另使用 Playwright + Chromium / WebGL 软件渲染测试真正的 3D 编辑器。截图和结果记录上传到 Actions 的 `shape3d-topology-screenshots` 工件（正面、背面、3/4、低角度及后续造型），供多机位人工复查。不应把自动化断言等同于完全的美术/视觉验收。
