# 人物资产工作约定

继续人物、服装、配饰或动作任务前，阅读 [生产约定](docs/CHARACTER_PRODUCTION.md)，再按任务需要阅读 [动作流程](docs/WORKFLOW.md) 和 [少年制作记录](docs/CHARABUILDER_BOY.md)。

- 仅提出新动作时，默认复用当前装配少年，不重建人物；明确要新造型 / 新角色时，按生产约定生成独立资产，保留认可的少年作为基准。
- 服装拟合同时核对身体和内层衣物：外穿上衣需避让实际裤腰，检查静止与动作中的层间距，不能只凭单件法线通过判定无穿模。
- 服装先拟合真实基础体，肩袖腋窝连续处理，再重设权重与折角法线，最后分件。删除衣内皮肤前保存未遮挡源数据；更换覆盖范围时重算遮罩，不能把穿衣对比体当完整裸身体。
- 配饰分件并按实际归属绑定：帽子随 Head、鞋底随对应 Foot、手持物独立校准。帽口保留可见发层，帽带位于发层外；不要统一剃平发层来藏穿模。
- 动作绑定保留掌面校正和经验证的锁骨适配，实时与烘焙导出共用；新人物不能直接套用少年的肩部参数。新增动作必须检查自己的采样，内置动作的通过结果不能代替新动作验证。

- 制作前先检查用户现有仓库、预设和资产。能复用时，拆解原始模型、保留比例和骨架、减面后重新装配，只补缺失部位。
- 没有合适现成资产时，依次寻找许可明确的开源低模项目、三视图设定、单张参考图；最后才用生图补充三视图。不得完全凭感觉起模后再修大比例。
- 记录来源网址、固定提交、许可、原始尺寸、部件和面数。生成概念图必须标明身份，不冒充原模型的精确三视图或拟合真值。
- 分件按材质、连通组件、关节语义处理，保持装配坐标。简化时保留 UV、蒙皮、材质与必要的边界；避免分别减面破坏共享接缝。
- 衣物和配件必须对照真实基础体拟合。灰模先验轮廓，不用双面材质或贴图明暗掩盖结构错误。
- 每轮检查正面、侧面、背面、四分之三、斜前俯视和斜后俯视，以及至少一个实际动作。第一轮发现问题后再修正并复查。
- 数值测试不能代替美术判断；明确说明未验证的渲染路径和局限。
- 用户需要外部可访问的 GitHub Pages 预览。完成常规修改、提交和发布后核对公开页，不以 localhost 代替交付。
