继续人物、服装、配饰或动作任务前，阅读 [生产约定](docs/CHARACTER_PRODUCTION.md)，再按任务需要阅读 [动作流程](docs/WORKFLOW.md) 、[少年制作记录](docs/CHARABUILDER_BOY.md) 和 [西装青年记录](docs/SUIT_MAN.md)。

继续“背心、瑜伽裤女性跑步角色”时，另读 [该任务交接](docs/RUNNING_WOMAN_HANDOFF.md)，先核对其中基线与实际进度；文档中的计划不代表已经完成。

握拳更新已公开发布并完成实际网页复查，44 项工程检查通过。跑步双手松握拳，挥手恢复张掌；“手部”近景随右手摆臂跟随。公开文件与提交逐字节一致，网页实际导出保留 30 条指骨轨道；当前发布与验证范围见 [握拳更新检查](docs/RUNNING_HANDS_VALIDATION.json)。此前授权及审批记录已解决，不是当前待办。

该女性角色现已实现，继续修改时优先阅读 [女性跑步制作记录](docs/RUNNING_WOMAN.md) 和对应来源、构建 / 验证 JSON；历史交接中的“尚未制作”描述的是开工状态。公开入口 `?model=runner` 默认播放实际跑步。新跑步保持独立方案，不将旧三段的采样数量冒充跑步覆盖。

- 仅提出新动作时，默认复用当前装配少年，不重建人物；明确要新造型 / 新角色时，按生产约定生成独立资产，保留认可的少年作为基准。
- 新建角色默认采用**二次元低面建模风格**，以《塞尔达》《原神》的风格化观感为方向：清晰轮廓、简洁二次元面部、分块发束、清爽配色与卡通光影。脸、身体、头发、服装保持统一风格，比例匹配年龄和角色设定；具体面数服从轮廓与变形需要。该默认用于后续新角色，当前资产的后续重做需有对应任务。完整规范见生产约定的“默认美术风格”。
- 服装拟合同时核对身体和内层衣物：优先内收下摆遮盖的内层裤腰，保留认可的上衣外轮廓，不默认外扩成宽松桶形。检查静止与动作中的层间距，不能只凭单件法线通过判定无穿模。
- 服装先拟合真实基础体，肩袖腋窝连续处理，再重设权重与折角法线，最后分件。删除衣内皮肤前保存未遮挡源数据；更换覆盖范围时重算遮罩，不能把穿衣对比体当完整裸身体。
- 配饰分件并按实际归属绑定：帽子随 Head、鞋底随对应 Foot、手持物独立校准。帽口保留可见发层，帽带位于发层外；不要统一剃平发层来藏穿模。
- 动作绑定协调前臂与手掌，不把朝向补偿全压在手腕上；检查完整动作和导出动画的绕轴范围与相邻帧连续性。保留掌面校正和经验证的锁骨适配，实时与烘焙导出共用；新人物不能直接套用少年的肩部参数。新增动作必须检查自己的采样，内置动作的通过结果不能代替新动作验证。

- 新角色默认具备可用的双手五指骨骼与蒙皮；手指绑骨不等于动作已制作手型。新动作明确 `hands`；跑步默认双手自然松握拳 `looseFist`，四指内收、拇指自然靠拢；挥手用 `open`，放松站姿用 `relaxed`，明确攥拳才用 `fist`。按目标实际指骨轴校准并检查拇指 / 指根蒙皮。手型必须同时进入实时和烘焙导出，切换旧动作或形体检查时清除残留；不能用转动手腕代替屈指。

- 长袖肘部的弯曲 / 扭转辅助骨也必须烘焙导出；导入的静止姿态、脚骨层级、实际指根需独立检查。局部动作补面与简化分别统计，不为固定减面比例牺牲变形质量。
- 无袖人物也要验证外露肩臂。女性跑步使用膝部半角辅助骨与肘 / 前臂辅助骨；裆部中线权重连续过渡，裤脚协调鞋领。实际鞋底接地校正与腾空量同样烘焙导出，不能只按脚骨高度判断。仍不声称完整足部 IK 或恒速无滑步。
- 制作前先检查用户现有仓库、预设和资产。能复用时，拆解原始模型、保留比例和骨架、减面后重新装配，只补缺失部位。
- 没有合适现成资产时，依次寻找许可明确的开源低模项目、三视图设定、单张参考图；最后才用生图补充三视图。不得完全凭感觉起模后再修大比例。
- 记录来源网址、固定提交、许可、原始尺寸、部件和面数。生成概念图必须标明身份，不冒充原模型的精确三视图或拟合真值。
- 分件按材质、连通组件、关节语义处理，保持装配坐标。简化时保留 UV、蒙皮、材质与必要的边界；避免分别减面破坏共享接缝。
- 衣物和配件必须对照真实基础体拟合。灰模先验轮廓，不用双面材质或贴图明暗掩盖结构错误。
- 每轮检查正面、侧面、背面、四分之三、斜前俯视和斜后俯视，以及至少一个实际动作。第一轮发现问题后再修正并复查。
- 数值测试不能代替美术判断；明确说明未验证的渲染路径和局限。
- 用户需要外部可访问的 GitHub Pages 预览。完成常规修改、提交和发布后核对公开页，不以 localhost 代替交付。
