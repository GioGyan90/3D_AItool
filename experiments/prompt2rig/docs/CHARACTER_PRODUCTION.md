# 人物、服装、配饰与动作的生产约定

## 默认选择

后续只提出动作需求时，直接使用当前装配少年，生成新的动作方案并绑定；不因动作提示词中出现人物描述而重建角色。需要不同人物或明确要求新造型时，再走新模型流程。当前默认模型也可用于其他角色的动作草稿，最终接入新角色时重新检查接触、比例和蒙皮。

- 在线入口：[人物动作实验室](https://giogyan90.github.io/3D_AItool/lab/)。
- 当前模型：[`reassembled-boy.glb`](../public/lab/characters/teen-boy/reassembled-boy.glb)。
- 来源与参数：[`manifest.json`](../public/lab/characters/teen-boy/manifest.json)、[`preset-state.json`](../public/lab/characters/teen-boy/preset-state.json)、[许可记录](../public/lab/characters/teen-boy/SOURCES.md)。
- 本次用户反馈“好多了”的实现基准：[2b3d0d9](https://github.com/GioGyan90/3D_AItool/commit/2b3d0d9ef745a726e18f54e9a18805da7eaed019)。继续工作先核对远程 main；此提交用于追溯，不要求退回旧版本。

## 默认美术风格（用户于 2026-10-30 指定）

后续新建角色默认采用**二次元低面建模风格**，以《塞尔达》《原神》的美术观感作为方向。素材选择、形体、头脸、发型、服装、配饰与材质统一按此目标制作；用户为某一角色另行指定风格时采用该角色的明确要求。

- **形体与面部：** 风格化且容易辨认的轮廓，简洁的二次元眼睛与五官，干净的面部转折。头身、肩颈、手脚和五官比例匹配角色年龄与设定；成年角色保持成年特征。
- **头发与衣饰：** 用清晰的发束、服装大形和少量关键结构表达设计。面数优先保障脸部轮廓、关节弯曲、衣物开口与可见配饰，逐件记录实际面数，按轮廓和变形需要决定预算。
- **配色与光影：** 清爽、可区分的色块，简化的材质细节，以卡通光影和赛璐璐感作为表现目标。材质与几何共同服务轮廓和体积；记录实际采用的渲染方案及尚未实现的效果。
- **素材筛选：** 按既有来源顺序寻找符合该风格的资产，确认头脸、身体与衣饰的风格一致，再做简化、拟合和装配。逐项说明头部与身体是复用素材还是自行构建，以及改造范围。

两作在这里用于确定美术方向，实际几何预算由本项目的用途、轮廓与变形要求决定。该约定适用于后续新角色；本次没有要求重新制作现有少年、西装青年或跑步女性。

## 默认手型与指骨验收（用户于 2026-10-30 确认）

新角色默认具备可用的双手五指骨骼与蒙皮。为每个新动作明确左右手型，并在目标角色上实际屈伸检查；骨架列表存在指骨只是开始，还要确认动作指令、蒙皮变形与导出轨道都有效。

| 动作语义 | 默认手型 | 检查重点 |
| --- | --- | --- |
| 跑步 | 双手 `looseFist`，自然松握拳 | 四指内收、拇指靠拢，掌面随摆臂自然朝向，腕部稳定 |
| 挥手 | `open`，张掌 | 掌面可读，手指自然展开 |
| 放松站姿 / 待机 | `relaxed`，自然微屈 | 手指放松，左右手按动作需要独立设置 |
| 明确要求攥拳 | `fist`，握拳 | 指节与虎口变形、拇指位置和掌内接触 |

按目标实际指轴与绑定姿势校准，检查双手、不同摆臂相位、指根 / 指节 / 虎口表面和局部穿插。指骨与身体共用实时、烘焙和 GLB 导出流程，导出重载后复核；切换无手型旧动作或形体检查后清除残留。当前协议支持整段固定手型，逐指关键帧与手型随时间变化仍需另行实现。

## 本轮反馈固化为验收规则

- **手腕异常先测量。** 分清累计来回角度、局部关节偏转和连续绕轴旋转；完整动作与导出动画都采样。掌面补偿由前臂与手腕协调承担，不能仅看首末帧或只修一只手。
- **先收内层裤腰。** 合身上衣的轮廓通过后，优先内收下摆遮盖的裤腰，并用短过渡和协调权重衔接；保留裤腿，不默认把上衣外扩成宽松款。
- **新人物单独适配。** 青年西装男士见 [制作记录](SUIT_MAN.md)，使用独立成年素材，少年保留为默认。不同年龄基础、骨架、衣物覆盖与动作检查分别记录。

## 服装：先确定覆盖，再做连续结构

1. **保存完整基础体和服装参数。** 保留未裁切的源数据，装配体的删面结果另存。`source-preset.glb` 是穿原衬衫的对比体，本身已有源服装遮罩，不能当成完整裸身体。需要恢复皮肤或制作不同覆盖范围的服装时，从同一固定来源与参数重新生成未遮挡基础体；当前构建器使用 `createHuman({...state, clothes:'underwear'})` 取得它。
2. **复用合适的现成服装。** 先看原服装的拓扑、裁片和权重。衣长、袖长、腰围、鞋面范围以真实模型为基准。原网格变形质量足够时直接保留；肩腋结构不适合时，允许使用同一基础体的连续拓扑重建相应服装区域，并准确记录改造范围。
3. **肩、袖、腋窝连续处理。** 当前 T 恤从同一少年基础体的上身拓扑拟合，参考原衣长和袖口，放松躯干与上臂廓形，裁出领口、下摆和短袖。长边先做共享中点细分，计算权重和法线后再拆成衣身、左右袖、肩腋片，保留相同接缝位置和权重。不要分别简化新接缝。
4. **把服装撑在实际身体外。** 使用平滑的躯干 / 肢体拟合场控制松量，检查肩峰、腋下、胸背和领口；不把皮肤每个细小凹凸沿原法线直接挤出，避免放大凹槽或产生翻折。领边沿实际开口建立，不能用一圈长三角面从袖口径向拉到领口代替整个肩部。

   **同时校验衣物之间的层次。** 身体松量不等于内层衣物松量。保持已认可的服装外轮廓，优先将下摆遮住的内层裤腰收紧，留间距；只在被遮盖的腰部及短过渡带调整几何和权重，裤腿保留。必要时局部细分，并匹配内外衣物的变形。不要默认把上衣撑成宽松桶形来避让裤子。只检查单件法线不会发现衣裤穿模。
5. **删除确定被遮挡的身体面。** 从装配体实际删去衣内的身体索引，而不是只设置不可见。保留领口、袖口、裤脚之外的皮肤；边界留少量衣内重叠，当前短袖约 9mm。身体遮罩必须随新服装的覆盖范围重算，不能把 T 恤遮罩直接沿用到背心或裸上身。
6. **正确处理肩袖蒙皮。** 胸部、锁骨与上臂之间平滑分配影响，控制过渡范围，避免同一处同时混入互相冲突的权重。当前模型用现有肩骨随抬臂上提、随手臂前伸而前伸；骨长不变。`shoulderRhythm` 是该预设的适配开关，不应未经验证套给所有外来骨架。
7. **法线跟随真实结构。** 全衣先计算面朝向和折角分组法线，再分件。腋窝两侧接近相反的面不能简单平均成向内的顶点法线。灰模、真实材质和实际变形都要检查；双面材质、阴影或贴图不能代替拓扑修复。

实现入口：[整体构建](../tools/build-charabuilder-boy.mjs)、[连续 T 恤](../tools/teen-shirt.mjs)、[衣内皮肤裁切](../tools/teen-boy-accessories.mjs)。当前是固定服装资产，不是通用自动裁衣或布料模拟系统。西装案例沿用源裁片和外露手头，不额外补衣内身体；换装需要另一套完整基础体，不能把删面或原本就不含身体的衣服装配体当裸身体。

## 配饰：分件、拟合、遮挡与骨骼归属

| 部件 | 当前做法 | 验证重点 |
| --- | --- | --- |
| 帽冠与后帽檐 | 按源头发体积拟合；反戴帽檐位于脸部反方向 | 正侧背、前后俯视；厚度、闭口和穿插 |
| 帽带开口与发层 | 帽口做成真实弧形开口，按该轮廓裁发；保留开口后面的源头发 | 透过开口应先看见头发；不能统一水平剃掉帽内发层后露出额头 |
| 调节带与带扣 | 青绿弧形帽带位于发层外，独立黄铜扣与红帽形成区分 | 带子不能埋进头发；端部衔接、颜色、厚度和头部转动 |
| 鞋面与鞋底 | 保留原鞋面，鞋底按原鞋实际轮廓拟合，独立分件 | 鞋底方向、脚部跟随、落地高度与动作穿模 |
| 后续手持道具 | 独立于人物和头发建模，校准手部插槽、握持与释放 | 不随头部错误运动；接触与约束需另做，当前工具没有通用自动道具拆解功能 |

帽冠、后帽檐、帽带、带扣、顶扣全部跟随 Head；左右鞋底分别跟随对应 Foot。刚性配饰可使用单骨权重；跨关节的软配件需单独设计蒙皮。查看时的分块拆解位移不能进入装配导出，单件导出也保留原装配空间。实现见 [配饰构建](../tools/teen-boy-accessories.mjs)。

## 制作新模型

按以下顺序寻找结构依据：用户已有仓库 / 预设 → 许可明确的开源低模资产 → 三视图设定 → 单张参考图并生图补全三视图。生成图是造型参考，不是已测量的精确几何。

- **固定比例和来源。** 先确定角色类型、头身比例、身高、服装覆盖、发型和配饰。保存来源链接、固定提交、作者、许可、参数、原始面数和尺寸。不同年龄 / 体型基础分别处理；尤其不能用少年脸的大范围变形冒充独立成男基础。
- **拆解后简化与装配。** 按材质、连通组件和关节语义拆解；清理未引用缓冲，保留 UV、有效权重、骨骼和必要边界。适当减面后再补缺件，保持统一坐标与对称关系，逐次记录实际面数和文件大小。
- **分清几何简化与动作补面。** 分面法线可能把每个面锁成独立边界；可重建法线时先焊接再简化，仍保留 UV 和蒙皮边界。肩腋 / 肘部为避免折叠而新增的局部细分单独计数；最终面数可以高于单纯减面阶段，不以牺牲变形质量满足固定百分比。
- **检查骨骼的真实语义。** 导入的打开姿势未必是绑定姿势，脚骨也可能是独立 IK 控制器。先恢复逆绑定矩阵对应的姿势，再统一坐标；修层级时保留关节世界位置并重算绑定。掌部同点辅助骨不能当真实食指 / 中指 / 小指根。
- **长袖另做肘部适配。** 掌面校正带来的前臂轴向旋转，不应全部挤在肘部一圈；需要时增加弯曲 / 扭转辅助骨，沿袖管平滑分配。新增辅助骨必须写入实际导出动画；只在实时画面更新不算完成。肩部节律按新人物的尺度与动作测量，不照抄少年的参数。
- **先处理结构，再着色。** 沿上面的服装与配饰约定拟合，确认颈口、肩峰、腋窝、髋腿、鞋底及发帽衔接；不先重做整个人物再追补比例。新建独立灰模只在没有合适源资产时使用。
- **接入现有动作链。** 验证朝向、尺寸、A/T 静止姿态、骨名和映射。当前工具可优化已有 GLB，但不自动给无骨架模型生成骨架或蒙皮。一个新角色的源参数、生成器与输出目录应独立保存，作为新增人物选项接入，不覆盖认可的少年基准。
- **给出完整交付记录。** 保存可复现构建方式、来源、统计、实际检查结果和未完成项；提交并发布外部可访问的预览。未完成某个视角或渲染路径验证时直说，不把数值通过写成美术验收通过。

## 使用当前或新人物制作动作

1. **确定动作本身。** 记录动作、时长、是否循环、站立 / 位移、左右手、关键接触点与道具。未要求换角色时使用当前少年。一个动作尽量包含准备、主要动作、停留 / 反应和还原，差异体现在身体动作而非字幕。
2. **按统一协议生成。** 使用 [WORKFLOW.md](WORKFLOW.md) 的聊天任务或 API 流程，输出 `motion-plan v1` JSON。标准驱动骨架是 T-pose，角色左侧 +X、向上 +Y、向前 +Z，局部 XYZ 欧拉角使用度，root 使用米；不要直接把目标 A-pose 骨架的角度抄进方案，也不要重复叠加肩部补偿。
3. **烘焙并重定向。** `planToTake → applyRetarget / retargetTake` 将方案绑定到当前角色。掌面朝向要与前臂协调，避免让手腕独自承担 A/T 姿态与轴向校正；给前伸动作明确掌面平面，避免沿前臂方向退化时绕轴翻转。保留当前少年的锁骨适配。关键关节和根位置都要产生可见的变化。使用可选 `hands: {left,right}` 为整段选择张掌、放松、松握拳或握拳；跑步用 `looseFist`，挥手用 `open`。目标须有可识别的实际指骨，指轴按自身绑定姿势测量；30 根指骨与身体同时烘焙。切换无手型的旧动作和形体检查时恢复源姿势。逐指关键帧、球杆接触、足底滑动和道具约束仍另行检查。
4. **检查实际新动作。** 查看首尾、抬臂峰值、最大前伸、转身和接触时刻，覆盖正 / 侧 / 背 / 四分之三 / 斜前俯视 / 斜后俯视；发现问题后修正并复查。当前 `check-teen-deformation.mjs --sweep` 只覆盖内置挥手、庆祝、俯身三段，154 个采样不能证明任意新生成动作通过；新动作需追加对应采样检查。
5. **导出并重新加载。** 导出完整人物与当前动作 GLB，或单独保存方案 JSON。涉及基于实际网格的接地 / 接触校正时，应在重定向烘焙前临时恢复装配；只在 GLB 写出前恢复，仍会把拆解几何算进动作轨道。用重新加载后的 AnimationMixer 确认肩骨、手掌、配饰跟随和时长；检查没有把灰模、孤立零件、线框或拆解位移写入成品。仅将 JSON 导入另一项目不代表该项目已实现同样的重定向与补偿。

网页 API 未选择提供商时默认 OpenAI；用户可填写自己的服务地址、协议、模型和 Key。网页不能借用聊天凭据。在聊天中制作 JSON 时可直接沿用这套协议，不需要网页再次调用付费模型。密钥不得写入任务、仓库或导出文件。

## 成年女性跑步补充

[女性跑步记录](RUNNING_WOMAN.md) 保存具体制作与验证；来源先查 CharaBuilder 成女入口，确认尚待建立后才使用独立成年 CC0 基础。`?model=runner` 新增独立人物并默认播放 4 秒循环，原有少年 / 西装保留。

- **无袖衣服与裸露皮肤都测。** 领口、袖窿的松量需沿开口渐减并有真实包边和衣内皮肤重叠，外层径向挤出后直接删除内层会留下漏缝；数值法线正常不能证明开口闭合。背心若继承上臂权重，垂臂时袖窿会折叠；它主要随胸和少量锁骨运动。肩膀、腋窝和裸手肘仍是需要验证的真实表面，不能只检查衣物后宣布动作通过。
- **屈膝与跨中线连续。** 大幅回收的膝窝需要按实际半径和屈曲角度安排过渡及半角辅助骨；裆部不能用 X 正负突然切换腿权重。新增骨骼也进入真实导出轨道。
- **脚底接触与腾空分开定义。** 标准动作先校准各支撑 / 腾空相位的足部高度，再在目标实际鞋底表面做高度校正。垂直校正不等于完整足部 IK；原地跑按虚拟地面速度评估，需要前进位移时重新协调 root 速度、步幅和支撑相位。
- **检查数必须对应当前动作。** 新跑步有独立的 242 姿势、241 个烘焙旋转采样、真实腰部截面及全部顶点导出重载检查；旧三段仍保留原覆盖。工程现在 44 项检查，另含 4 项手型协议、实际双手、切换清理和烘焙一致性检查。
