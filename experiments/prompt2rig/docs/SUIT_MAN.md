# 青年西装男士制作记录

公开预览：[直接打开西装青年](https://giogyan90.github.io/3D_AItool/lab/?model=suit)。未带人物参数的入口仍默认少年；下拉菜单可以在两个独立人物、各自的源形体和旧灰模之间切换。支持原材质、灰模、分部色、线框、单件、拆解、内置动作、提示词 / 聊天 JSON 与人物动画导出。

## 来源与结构依据

先检查了用户 CharaBuilder 的成年预设。现有 Stone C 主要是成熟肌肉体型，因此选用 Quaternius 的 **Business Man / Ultimate Modular Men Pack** 作为独立成年基础。已查看作者套装预览图，保留成年头脸、侧分短发、头身比例、原西装裁片、手指和皮鞋；没有从少年脸变形成男。

具体作者发布页、CC0 证据、固定镜像提交、未经改动的原 GLB 链接、SHA-256 以及改造范围见 [SOURCES.md](../public/lab/characters/suit-man/SOURCES.md)。许可根据具体资产条目与套装页判断，不由作者网站其他新产品的条款推断。

造型为藏蓝西装、暖白衬衫、酒红领带、深色皮鞋和侧分短发。原头身与关节比例仅统一缩放：绑定姿态原高约 1.85693 米，成品高 1.80 米，脚底对齐地面。衣内不额外添加完整身体；源身体部件实际上只有外露手，头部另件，不能把这套衣服当完整裸身体。

## 骨架、服装与动作适配

1. **恢复绑定姿势。** 原文件打开时处于非对称动画姿势，不能当建模静止姿势。由逆绑定矩阵恢复 T 姿势；四个皮肤共享骨骼，只恢复一次，各网格仍使用各自的逆绑定矩阵。之后将几何、法线和关节烘焙到共同坐标，以统一的静止旋转重新绑定。
2. **按实际功能映射骨名。** `Body` 是驱动双腿和脊柱的主髋；源 `Hips` 保留为脊柱间的附加节点。脚骨原本独立在 Root 下，将其接回对应小腿，保留原世界位置。源 `Index/Middle/Ring/Pinky 1` 是同点的掌部辅助骨，实际指根用 `*2` 映射到标准 `Hand*1`，避免掌面坐标退化。
3. **原服装简化后补变形结构。** 在材质区域中保守减面，保留 UV、蒙皮与材质边界；分面法线可重建时先焊接，再减面、重算法线。源肩腋 / 肘部在动作中会翻折，因此在原表面共享中点细分，重新设置胸、锁骨、上臂、肘和前臂权重，最后才语义分件。所有新增点位于原表面，不外扩衣身，也不重塑裤腿。
4. **长袖分摊弯曲与旋转。** 每侧两根辅助骨：肘部骨承接部分弯曲和轴向旋转，中段骨再向实际前臂平滑过渡；袖管沿长度分配影响，避免在肘部一圈突然转向。两侧共四根辅助骨同样进入烘焙轨道。手掌仍使用实际指根的解剖坐标，手腕不独自承担约 90° 的朝向校正。
5. **独立校准肩部。** 该人物的抬肩增益 `.3`、最大抬肩 `.32 rad`、前伸增益 / 上限 `.35 rad`，由本人物采样校验；没有直接启用少年的布尔适配参数。上臂靠近肩部使用平滑过渡，远离肩部使用较均匀的梯度，避免锁骨与肘部权重叠加产生局部压扁。
6. **导出实际动画。** 52 根标准骨骼加 4 根辅助骨，共 56 根动作轨道；实际骨骼节点 70 个。导出重新加载后，用 AnimationMixer 复现辅助骨和西装顶点，和实时结果逐点比较。原素材的 24 段动画保留在固定源链接中，没有把旧名称 / 旧层级的轨道直接搬到新装配体。

共 19 个装配零件：西装衣身、左右衣袖、内搭衬衫、领口、左右袖口、领带、裤腰、左右裤腿、左右皮鞋、头颈、短发、眉毛、眼睛、左右手。

- 工程共 **36 项测试**：原有 30 项加 6 项西装人物检查，覆盖独立来源 / 比例、有限几何与归一化权重、脚链、加载器与拆件、掌面、导出辅助骨与实际变形一致性、完整动作服装和手臂旋转。
- [服装报告](SUIT_DEFORMATION_VALIDATION.json)：挥手 4 秒、庆祝 5 秒、俯身 6 秒，加静止姿态，共 154 个采样姿势、11 件服装。最小法线对齐约 0.14785，最小面积比约 0.10898，未发现翻面或低于 0.1 面积比阈值的三角面；最大边伸长约 1.875 倍。此为 10Hz 采样，不是布料质量的完整证明。
- [手臂报告](SUIT_ARM_ROTATION_VALIDATION.json)：导出骨骼动画 60fps、共 903 个采样；相邻帧最大旋转约 6.57°，手腕最大局部角约 20.88°，轴向变化范围最大约 86.91°。来回运动的累计角度不等于连续转圈。

数值结果不代替美术验收。本轮浏览器预览访问仍受此前自动审批限制约束，未重新访问被拒来源，也未用替代渲染绕过；**尚未完成新人物的正 / 侧 / 背 / 四分之三 / 前后俯视与实际动作视觉复查**。没有宣称任意动作无穿模；衣物间、鞋底接触、极限拉伸、GPU 与兼容模式的显示仍需在公开页评审。

## 重建与验证

从固定源链接下载 `Business Man.glb` 后，在实验目录执行；构建器核对 SHA-256 后才处理，不改动源文件。

```sh
SUIT_MAN_SOURCE=/path/to/Business-Man.glb node --experimental-loader ./tests/vendor-loader.mjs tools/build-suit-man.mjs
npm test
node --experimental-loader ./tests/vendor-loader.mjs tools/check-teen-deformation.mjs public/lab/characters/suit-man/assembled-suit-man.glb --sweep
node --experimental-loader ./tests/vendor-loader.mjs tools/check-teen-arms.mjs public/lab/characters/suit-man/assembled-suit-man.glb
```

共享检查器保留旧文件名，但会根据人物元数据检查对应的服装区域。Windows 可先用 `$env:SUIT_MAN_SOURCE="C:\path\Business-Man.glb"` 设置路径，再单独运行 Node 命令。网页更新后从仓库根目录运行 `node experiments/prompt2rig/tools/build-pages.mjs`，连同根 `docs/` 提交发布。
