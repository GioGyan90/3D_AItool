# CharaBuilder 少年：复用、拆解、减面与重新装配

默认人物来自用户自己的 [CharaBuilder](https://github.com/GioGyan90/CharaBuilder/tree/6ff7fa5c7b451c7318cf445038f1514a646343ea) 少年预设。头身比例、脸部、骨骼及四肢长度以原预设为基准，仅统一缩放。之前的独立截面灰模保留作对比，不再作为这个人物的身体。

通用的服装 / 配饰规则、默认模型复用和新角色 / 新动作生产入口见 [CHARACTER_PRODUCTION.md](CHARACTER_PRODUCTION.md)。

## 拆解和减面

先将共享大缓冲按可见索引紧凑化，再按材质简化。眉毛、虹膜、眼白、高光、眼线等细小组件保留面数；面部皮肤保留较高比例，衣裤承担主要减面。保留 UV、材质和原骨骼索引；T 恤的肩袖权重另行重设。逐材质 history 是服装重构前的减面阶段，最终网格以 parts 和 after 为准。简化完成后再沿关节与服装语义分件，避免分别简化新接缝使两边错开。

最终装配体有 37 个网格零件：五官 / 皮肤 / 耳部、斜刘海 / 原短后发 / 侧发 / 帽内发底、颈部与后脑、双臂 / 双手 / 脚踝、衣身 / 短袖 / 肩部补片 / 圆领、裤腰胯 / 裤腿、鞋面 / 鞋底、反戴帽五件。保留 91 个实际骨骼节点，其中 52 个被标准动作驱动器识别。

- 原人物 23,922 三角面；补件后 15,286 三角面，减少约 36.1%。
- 源几何紧凑化并拆件后 16,045 顶点；最终装配约 10,752 顶点。原运行时共享缓冲含额外未引用顶点，不能把它们当作美术细节减少量。
- 同样嵌入贴图、同样压缩的对比 GLB 约 999.5 KiB；装配体约 827.6 KiB。实际大小见 [逐件报告](CHARABUILDER_BOY_VALIDATION.json)。

反戴帽的帽檐全部位于脸部反方向。额前帽口使用明确的弧形开口，按帽口轮廓保留里面的源头发，避免额头皮肤直接露出。青绿调节带沿弧面位于发层外，配独立黄铜带扣。鞋底根据原鞋的范围拟合。

T 恤改用同一少年基础体的连续上身拓扑构建，按原衣长和袖长裁切，并用平滑的躯干 / 上臂场放松廓形，避免将皮肤细小凹凸沿法线挤出成翻折。肩、腋窝、衣身和短袖共用拓扑与权重场，细分长边后再按零件拆开。法线按真实折角分组，避免腋窝两侧方向相反的面被平均成向内的法线；仍使用正面材质。

下摆现在根据实际裤腰建立带余量的外包截面，细分下摆长边，交叠区域统一跟随骨盆，再向躯干平滑过渡。裤子原几何与权重保留。

锁骨随抬臂适度上提，手臂前伸时适度前伸。原骨骼比例不变；相关姿态写入现有肩骨动画轨道，实时预览、烘焙和导出共用。

## 本轮修正

- 默认前发改用捏人仓库现有 `swept` 层次斜刘海，后发和侧发保留短发，发际线参数 35；头脸和身体比例不重新建模。
- 手臂方向重定向后，再根据腕 / 食指根 / 中指根 / 小指根建立掌面坐标，独立校正手掌旋转。挥手掌心朝前，保留手腕动作，实时和烘焙导出使用同一处理。
- 源预设已省略衣裤内的大部分躯干 / 腿部皮肤；本轮进一步删除短袖内上臂和圆领外肩部残留。袖口按原上臂轴裁切，留约 9mm 衣内重叠，颈部按圆领内轮廓保留。不是隐藏渲染：导出的 GLB 也不包含这些身体面。
- 本轮以连续肩腋拓扑替换旧径向肩片，重分肩 / 袖 / 胸权重，并增加锁骨抬升、前伸；帽带开口保留发层、加宽青绿帽带和独立黄铜带扣。
- 这是固定服装用模型，之后换成背心或脱去上衣时，应从同一来源与参数重建未遮挡基础体，再恢复相应皮肤、重算遮罩。`source-preset.glb` 是穿原衬衫的对比体，已有源服装遮罩，不能当成完整裸身体。

## 对比与导出

网页“人物方案”可以切换装配少年、原始少年和上一版灰模。三者使用相同相机，正 / 侧 / 背 / 斜侧、头部、前俯和后俯均可检查。显示原始材质、灰模、分部颜色、线框，或选择单件及分块拆解。

查看状态不会写进装配导出：导出临时还原所有零件、原始材质、坐标和线框状态，再恢复画面。单件 GLB 保留原装配空间，无蒙皮；完整人物与当前动作沿用已有导出流程。

## 可复现

从实验目录执行，Python 需安装 Pillow、NumPy。源仓库仅用于离线构建；网页不下载完整捏人工程。

```sh
git clone https://github.com/GioGyan90/CharaBuilder.git /path/to/CharaBuilder
git -C /path/to/CharaBuilder checkout 6ff7fa5c7b451c7318cf445038f1514a646343ea
CHARABUILDER_SOURCE=/path/to/CharaBuilder node --experimental-loader ./tools/charabuilder-loader.mjs tools/build-charabuilder-boy.mjs
npm test
```

Windows PowerShell 用 `$env:CHARABUILDER_SOURCE="C:\path\to\CharaBuilder"` 设置变量，再单独运行 Node 命令。逐件减面参数、固定预设参数和来源提交写入 `public/lab/characters/teen-boy/manifest.json`。

## 验证和局限

28 项自动检查通过。本轮数值检查覆盖帽口头发可见、帽带位于发层外、帽带 / 带扣跟随头骨、抬臂后锁骨上提、肩部表面覆盖、导出动画保留锁骨修正，以及原有的比例、蒙皮、接缝、GLB 导入导出和 API 行为。

[整段变形报告](TEEN_DEFORMATION_VALIDATION.json) 对挥手、庆祝、俯身出杆以 0.1 秒间隔检查，共 154 个姿势（含原始 A 姿势）。在四个上衣零件上，变形后的面法线与蒙皮顶点法线的最小点积约 0.238；三角面积与原始面积比最小约 0.143，没有低于 0.1 的塌陷或法线反向。局部边长可拉伸至约 3.97 倍，因此不是布料模拟或任意极限动作的保证。命令：

```sh
node --experimental-loader ./tests/vendor-loader.mjs tools/check-teen-deformation.mjs --sweep
```

[衣裤间距报告](TEEN_WAIST_VALIDATION.json) 在 154 个姿势中，以髋部局部截面检查上衣与裤腰交叠，截面层距 5mm、每层 96 个方向，共 330,939 个有效径向样本；最小采样间距约 16.2mm，无采样穿入。此检查不覆盖任意新动作或所有衣物接触。

本轮没有完成新的浏览器多视角 / 动作视觉复查。前一轮浏览器自动审批已将重新访问此前受限的预览来源判定为绕过，本轮未重试或替代该浏览器操作。数值检查不等同于美术验收；上衣轮廓、帽带配色和侧后衔接仍需在公开页评审。前一轮的截图只对应旧肩片，不能作为本轮完成的画面证明。

灰模与真实材质、多视角和动作仍需人工评审。当前环境使用带深度缓冲、贴图与 CPU 蒙皮的 Canvas 兼容渲染，未验证 GPU WebGL 路径；兼容模式的细节和速度不等同于正常 WebGL。衣物与人体仍是分件网格，非连续焊接的单一流形；极限动作接触和穿插没有穷尽测试。没有移植原捏人工具的表情与参数编辑能力。
