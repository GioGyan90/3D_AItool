# 拓扑工作台功能审计与窗口布局（2026-11-23）

## 目标和改动原则

保留稀疏的 `vertices` / `faces` 控制网格及现有几何算法，不使用大量规则网格替代建模。把随时需要看到的信息固定在右侧，把复杂参数放进独立滚动区，避免高度有限的浏览器窗口截断操作按钮。

## 重组结果

| 原有分布 | 新组合 | 原因 |
| --- | --- | --- |
| 全高常驻“当前选择”、编号输入和坐标 | 默认仅显示选择摘要，点“展开精确选择”再编辑编号/坐标/删除来源 | 不选元素时不挤占工具面板；需要时仍可完整编辑 |
| 布线、塑形、配色、检查随整个右栏滚走 | 四类页签固定，当前工具参数单独滚动 | 长面板与矮窗口下始终能切换操作 |
| 塑形页先展示大段 X/Y/Z 对称设置 | 内插、挤出优先，对称设置折叠在同页 | 优先呈现当前选中面可执行的动作 |
| 选面提示分别出现在选择卡与配色区 | 顶部汇总当前选择，配色区仅展示批量目标与着色按钮 | 避免重复状态 |
| 固定宽度 376px 的桌面侧栏 | 344–450px 自动适配；可手动展开至 660px 左右 | 笔记本与大屏同时留出足够三维画布 |
| 手机工具面板固定 46vh，整个侧栏一起滚动 | 保留画布的上下布局；右侧参数独立滚动；可一键全屏展开工具区 | 小屏下可以触及末尾操作而不被底部裁切 |

## 功能覆盖矩阵

下列“检查方式”指代码仓库中的验证路径。具体通过与否以对应 GitHub Actions 运行记录为准。

| 功能 | 检查方式 | 备注 |

| 创建基础立方体 / 六条环线生成魔方 | Playwright + 单元测试 | 8/6 → 56/54 |

| 面内插、面挤出 | Playwright + 单元测试 | 验证三角化与共享边 |

| 精确顶点移动、X/Y/Z 对称 | Playwright + 单元测试 | 移动后撤销 |
| 删除控制面、撤销恢复 | Playwright | 验证面数恢复 |
| 删除未引用顶点 | 静态权限条件 + 未引用顶点测试待补 | 不允许直接删除仍被面引用的点 |
| 选面、同平面/同色批选、自定义颜色 | Playwright + 单元测试 | 包括撤销/重做 |
| 清空颜色并撤销 | Playwright | 保留控制网格 |
| 正面/背面/3/4/低角度、重置视角 | Playwright 截图 | WebGL 模式 |
| 3D/正交切换、正交五机位、三种绘图模式 | Playwright | 画布与模式按钮切换 |
| X-Ray、控制网格/成品显示 | Playwright | 不修改模型拓扑 |
| 场景应用、重开编辑器 | Playwright | 顶点与面数不应漂移 |
| 独立参考窗口：JSON 导入导出、GLB 导出、3D 预览 | Playwright | 真实文件下载 |
| 新建空网格、保存并恢复旧网格 | Playwright | 不丢失备份 |
| 参考图标定、手工放点和连接成面 | 代码审计 + 原有正交控件 | 本轮可进一步补自动端到端测试 |
| 桌面矮窗口、900px 平板、390px 手机 | Playwright + 截图 | 检查工具面板、滚动和折叠 |
| 展开工具区、返回画布布局 | Playwright | 桌面变宽，手机全屏 |

## 验收命令和产物

- `npm ci && npm run lint`
- `npm run test:topology`
- `npm run build:pages`
- `node scripts/topology-visual-qa.mjs`（实际 Chrome/WebGL）
- 输出到 `artifacts/topology-qa/`，CI 自动上传多机位/布局截图及 `results.json`。
